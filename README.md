# Xpress Logistics Website

A responsive delivery company website for **Xpress Logistics** with:

- Package tracking by tracking ID
- Live visual map tracking (Google-Maps-style UX via Leaflet + OpenStreetMap)
- Admin controls to customize delivery location, hub, and ETA
- Contact support form for customer inquiries

## Run locally

Preferred preview command:

```bash
npm start
```

Alternative static command:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Demo tracking IDs

- `XP-1024`
- `XP-2048`
